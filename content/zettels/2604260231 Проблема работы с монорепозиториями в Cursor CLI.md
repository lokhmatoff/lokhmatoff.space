Git-ориентированный подход Cursor CLI [[2604260208 Cursor CLI определяет корень проекта по git|2604260208]] к определению корневой директории проекта создаёт неудобства в использовании, например, командой разработчиков определённого сервиса в монорепозитория настроенных инструментов ИИ-ассистированной разработки специфично для этого инструмента [[2604260217 Специфичные для поддиректории MCP серверы не видно в Cursor CLI|2604260217]]; такая команда вынуждена искать обходные стратегии, такие как создание отдельных рабочих пространств через символические ссылки или переход на Cursor IDE.

Отчёт об ошибке на форуме Cursor: https://forum.cursor.com/t/agent-cli-doesnt-read-cursor-directory-from-current-working-directory-in-monorepo-subfolder/150169
