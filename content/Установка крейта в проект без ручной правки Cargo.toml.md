Предполагается, что название [[Crates|крейта]] известно устанавливающему.

Вызываем менеджер пакетов/сборщик **Cargo** (например, для установки `rand`):

```bash
cargo add rand
```

**Cargo** автоматически проставит в `cargo.toml` и `cargo.lock` последнюю стабильную версию, которая будет совместима с версией [[Rust]] на текущей машине.
