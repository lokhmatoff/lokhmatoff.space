Механизм обмена сообщениями между сервисами, использующий сущность **каналы (Channels)** в [[Redis]]. Может послужить хорошей основой *широковещания событий* для [[Слабосвязное взаимодействие микросервисов|микросервисов]], написанных на [[PHP]] / [[tags/laravel|Laravel]], так как последний предоставляет [достаточно удобный интерфейс](https://laravel.com/docs/12.x/redis#pubsub) из коробки.

> [!question]- Почему именно широковещание событий?
> Для **лары** это, пока что, самый удобный из способов доставить событие для *многих сервисов-подписчиков* без доп. настройки блокировок или резервирования, а также без вложения зоопарка из межсервисных шин (поскольку приличное большинство laravel-бэкендов могут использовать [[Redis]] в качестве кеш-системы и дата-драйвера для воркеров очередей).
