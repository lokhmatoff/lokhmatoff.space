[[references/Cursor|Cursor CLI]] определяет корень проекта по расположению `.git`, а не по текущей рабочей директории в терминале. Запуск из подпапки **монорепозитория** поднимает весь репозиторий как корень, а не отдельный сервис или пакет.

**Следствие:** настройки агента в `.cursor/` у конкретного сервиса — отдельные MCP-серверы, правила — **не подхватываются**. Интерфейс предлагает всё сконфигурировать в корневом `cursor.json`.

**Что делать:** отдельное рабочее дерево git, симлинк-воркспейс или работа из IDE вместо CLI, если нужен конфиг «на уровне сервиса». Обходные схемы нестабильны.

Обсуждение на форуме: [тред про монорепо и CLI](https://forum.cursor.com/t/agent-cli-doesnt-read-cursor-directory-from-current-working-directory-in-monorepo-subfolder/150169).
