Есть гипотеза — *проект с не очень сложной бизнес-логикой можно реализовать на [[tags/laravel|Laravel]] и **FilamentPHP** за 1 человеко-неделю*.

Как будет проверяться гипотеза:

1. Возьмём из личного загашника 1 из 3 проектов, повторим следующие пункты 3 раза;
2. Напишем требования к проекту и спроектируем систему и хранение данных;
3. Напишем код проекта на **Laravel 12** и **Filament v3**, тесты к нему;
4. Развернём проект в публичном пространстве.

> [!bug] Низкая релевантность
> Эксперимент плохо ложится в научный метод, поскольку не описаны условия для реализации каждого из шагов проверки гипотезы, предметная область каждого из проектов отличается, воспроизводимость эксперимента также очень низка.
