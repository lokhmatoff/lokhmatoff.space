> [!tip] Клавишей `<leader>` по умолчанию является **пробел**

| Сочетание клавиш      | Действие                                               |
| --------------------- | ------------------------------------------------------ |
| `Shift + l`           | Переключиться на вкладку (буфер) справа                |
| `Shift + h`           | Переключиться на вкладку (буфер) слева                 |
| `<leader> + e`        | Тоггл сайдбара с NeoTree (дерево файлов\)              |
| `Ctrl + w + w`        | Переключиться на NeoTree и обратно                     |
| `<leader> + b + d`    | Закрыть текущую вкладку (буфер)                        |
| `Shift + h` (NeoTree) | Показать/скрыть скрытые файлы (часто начинаются с `.`) |
| `<leader> + g + g`    | Открыть панель версионного контроля (LazyGit)          |
| `<leader> + f + T`    | Запустить терминал в текущей рабочей директории        |
| `<leader> + f + t`    | Запустить терминал в корневой директории               |
| `g + c + c`           | Закомментировать/раскомментировать строчку             |

Список веду, в первую очередь, для себя, но, возможно, читателю это тоже будет полезно, если он уже работает в `nvim` или только учится, как я.
