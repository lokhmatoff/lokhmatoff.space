Список приложений, программ, сервисов и утилит, которые хочется попробовать и, возможно, включить в арсенал используемых.

- [ ] `bat` (Better `cat`) // утилита для чтения содержимого файлов в консоли;
- [ ] `zsh` // оболочка командной строки для [[tags/linux|Linux]] и **macOS**;
- [ ] `jq` // утилита командной строки для работы с структурируемыми данными (в частности, **JSON**);
- [ ] [Spacedrive](https://www.spacedrive.com/) // приложение для локального и облачного хранения файлов. ==Находится в альфе и доступно только для **Windows** и **macOS**==;
- [ ] [Coolify](https://coolify.io) // PaaS (Platform as a Service) для self-хостинга проектов, [Документация](https://coolify.io/docs/get-started/introduction);
- [ ] **Wave Terminal** // многофункциональный терминал с встроенным **ИИ**;
- [ ] **LocalSend** // Приложение для обмена файлами между устройствами в локальной сети.
